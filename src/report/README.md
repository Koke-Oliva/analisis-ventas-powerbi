# Extractos PBIR del informe

Esta carpeta contiene metadatos del informe PBIR usados para documentar la estructura del reporte.

Páginas del informe:
1. Resumen ejecutivo
2. Análisis comercial
3. Detalle comercial

La definición completa fue validada en Power BI Desktop durante la refactorización del proyecto. Se publican extractos técnicos para facilitar la revisión del portafolio sin redistribuir los archivos fuente académicos.
